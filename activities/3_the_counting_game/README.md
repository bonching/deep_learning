### 3. The Counting Game

* **Rationale:** Master loop mechanics (`while`) and state tracking with counters, which form the structural backbone of the main game loop.
* **Requirement Details:** Write a program that uses a `while` loop to count and print numbers from 1 up to 5, then stops.
* **Sample Input:** None (runs automatically upon execution)
* **Expected Output:**
```text
1
2
3
4
5

```


* **Hint:** Initialize a counter variable before the loop (e.g., `count = 1`) and make sure to increase it inside the loop (`count += 1`) to prevent an infinite loop.
* **Edge Cases:** Forgetting to increment the counter, causing the program to freeze or loop infinitely.
