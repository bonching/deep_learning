### 1. The Greeting Bot

* **Rationale:** Learn basic console input/output (`print()` and `input()`) and how to capture and reuse data stored in string variables.
* **Requirement Details:** Write a program that asks the user for their name, stores it in a variable, and prints a customized greeting message.
* **Sample Input:** `Alice`
* **Expected Output:** `Welcome to Tic-Tac-Toe, Alice!`
* **Hint:** Remember that `input()` always returns text (a string). You can combine variables and text using f-strings (e.g., `f"Hello {name}"`).
* **Edge Cases:** The user presses Enter without typing a name (results in an empty string).
